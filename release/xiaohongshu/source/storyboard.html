问题：摘要不等于全文

只看 Abstract，容易漏掉正文里的方法、实验、限制和反例。

先覆盖全文，再决定是否写入。

示意页面为虚构内容，不含论文截图。

结果：写入前先过三道门

  1. 完整页面覆盖与章节记录
  2. 原文 exact quote 精确匹配
  3. 唯一结果 + 坐标 + sortIndex

重复文本不会静默选第一个

可复核比“看起来完成”更重要。

怎么做到的？

  1. 读取 Zotero 已安装的 PDF.js
  2. 保留 Reader 的字符与空格语义
  3. 从字符几何合成原生 rects
  4. 最后才调用 Zotero 原生保存路径
后台处理，不依赖鼠标、键盘或前台 PDF 标签。

全文优先

purpose / gap / method / result

每个证据单元带原文、页码、章节和中文摘要。

颜色只是分类提示，不替代研究判断。

核心能力

  • Background PDF.js extraction
  • UTF-16 aware text mapping
  • Multi-line geometry
  • Context disambiguation
  • Duplicate protection
  • JSONL resume/audit
Node.js · Zotero 9.0.6 · local bridge

安全边界

  • 不直接修改 zotero.sqlite
  • 不上传 PDF 到项目
  • 不使用 OCR 或外部 PDF 解析器
  • 不执行 GUI 自动化
  • 写入前先 dry-run
Native write 仍会改变你的 Zotero 库，请先备份。

三步开始

  1. 安装 Zotero 与本地 bridge
  2. 运行 doctor + dry-run
  3. 人工确认后再 --apply
node src/doctor.mjs --json
node src/annotate.mjs --plan analysis.json
node src/annotate.mjs --plan analysis.json --apply
